# output/: generated validation artifacts

Everything here is generated by the `sttm-validator` agent. Original input files are never written here.

| Path | Description |
|---|---|
| `STTM_Validation_Report.xlsx` | Final report: **Summary**, **Record Validation**, **Field Validation**, **Exceptions**, **Rule Log**. It is overwritten on each run. If the file is open in Excel, a timestamped copy (`STTM_Validation_Report_YYYYMMDD_HHMMSS.xlsx`) is written instead. |
| `work/validation_config.json` | The STTM rules as encoded by the agent (with STTM sheet/row references). Review it to audit how each rule was interpreted. |
| `work/sttm_dump.md` | Text dump of every STTM worksheet with cell references, used by the agent to read the STTM. |
| `work/profile_<file>.json` | File profiles: structure, counts, masked value patterns. |
| `work/validation_summary.json` | Aggregate run statistics and reconciliation checks. Contains no record values. |
| `work/validation.log` | Run log with counts and structural messages only. Contains no record values. |

Very large results continue on extra sheets (for example `Field Validation (2)`) when a sheet
reaches Excel's row limit. The Summary formulas include all continuation sheets.

The report contains record-level values from your data. Treat it with the same confidentiality as
the inputs. `.gitignore` excludes generated files.
